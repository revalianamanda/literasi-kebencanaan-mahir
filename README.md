# E-Modul Literasi Kebencanaan

Membaca Kreatif Teks Persuasif Berbantuan Kecerdasan Buatan Generatif, beserta e-book pendamping *Bijak Bermitra dengan Kecerdasan Buatan Generatif*.

- `index.html`: e-modul
- `ebook.html`: e-book pendamping
- `config.js`: alamat server data (Google Apps Script)

Data jawaban siswa tidak disimpan di repositori ini. Data tersimpan di perangkat siswa dan di Google Sheets milik guru.
